Operating systems mediate between hardware and every other layer of software. They handle process scheduling, memory management, and I/O.

**Common sub-types:**
- Desktop — Windows, macOS, Linux distributions
- Mobile — iOS, Android
- Server — Windows Server, Linux server distributions (Ubuntu Server, RHEL)
